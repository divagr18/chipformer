# chipformer

Tetris, Space Invaders, Pong and more, running inside a transformer. There is no emulator here:
every pixel is the model predicting its next token. Its weights were set by hand and it never
saw a training example.

- Code: https://github.com/divagr18/chipformer
- Model: https://huggingface.co/divagr1925/chipformer
- Full site: https://divagr.com/chipformer

The page runs the model in your browser with a small WebAssembly engine (`assets/engine.wasm`)
over the sparse weights (`assets/model.chipformer`). Game credits are in
`assets/ATTRIBUTION.md`.

Generated by `python -m chipformer.web space` in the chipformer repo. Do not edit this copy by
hand.
