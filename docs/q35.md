# CHIP-8 inside a stock Qwen3.5 checkpoint

`chipformer/q35/` compiles the CHIP-8 machine into ordinary Qwen3.5 layers: Gated DeltaNet
(linear attention) plus SwiGLU MLPs. The result loads with the stock `transformers` classes and
needs no `trust_remote_code`. It runs exactly in bf16 and fp32, with the reference torch kernels
or with flash-linear-attention. The trace format is the same as the original chipformer
(`docs/trace_format.md`), so `chipformer/check.py`, `session.py` and the reference emulator are
reused unchanged.

## Ideas

- **Memory is the delta rule.** A DeltaNet head updates its state with
  `S += k (v - S^T k)^T`. With `beta = 1` and a one-hot key, that is an exact overwrite of one
  row. A one-hot query then reads the latest write. This gives RAM with no positions and no large
  attention scores, which is why float64 is no longer needed.
- **Norm isolation (ballast).**
  - Chip tokens carry `2^40` in `m` dims. With `m * 2^80 / hidden` a power of 4, every RMSNorm on
    a chip token divides by an exactly known power of 2, and the emitter folds that factor into
    the weights.
  - Text tokens carry no ballast, so every chip sublayer outputs exactly 0 on them. This holds
    because there are no biases, `z = 0` and `dt_bias = -110`.
- **bf16 exactness.**
  - Every materialized value has at most 8 significant bits: bits, one-hot nibbles, and integers
    up to 256. 12-bit quantities are built from a low byte and a high nibble.
  - `silu(K x)` with `K = 128` is an exact ReLU at every value the circuit produces.
- **fp32 exactness.**
  - ANDs, keys and queries use half-unit margins (`4 * (sum - n + 1/2)`), so a false entry is
    exactly 0 even when the literals carry noise.
  - Without the margins, a tiny leak into an unwritten row gets rescaled to full size by the
    per-head output RMSNorm.
- **Positions, replaced.**
  - The write index `j` comes from a head whose row halves at every VAL token and resets at
    STEP/BOOT, so `x = 2^-j`.
  - "Latest STEP" and "latest TICK" are rows that get overwritten at those tokens.
  - Display clear (CLS) is a decay-0 reset of the display heads.

## Files

| File | Role |
|---|---|
| `ir.py` | Graph of FFN / DeltaNet-head nodes, and an exact evaluator that also checks bf16 rounding at every intermediate |
| `prims.py` | Gadgets: ANDs, threshold tests, nibble arithmetic, slot heads |
| `chip8_q35.py` | The CHIP-8 circuit |
| `emit.py` | Weights, residual-slot sharing (liveness, with handover units), and the layout |
| `tiny.py` | Standalone stock `Qwen3_5ForCausalLM` (`python -m chipformer.q35.tiny`) |
| `merge.py` | Widen a Qwen3.5 checkpoint, append the chip layers, extend the tokenizer (`python -m chipformer.q35.merge SRC`) |
| `host.py` | Drives a checkpoint with `Session` (prefill plus cached decode) |
| `report.py` | Chip exactness, leakage and text fidelity of a merged checkpoint vs its base |
| `spike.py` | Phase 0 numerics: the primitives in real HF modules |

## Status

- **Circuit:** the IR evaluator equals the reference emulator on 1.08M tokens across all 119
  games, the Timendus test ROMs under every quirk profile, and fuzzed programs.
- **Tiny checkpoint** (351M, hidden 1024, 15 linear-attention layers plus one inert attention
  layer): token-exact in bf16 and fp32.
- **Merged checkpoints:**

| Base | Merged size | Chip | Text fidelity |
|---|---|---|---|
| Qwen3.5-0.8B | hidden 2048, 24 + 15 layers, 2.27B | exact, also inside a chat | KL 7.8e-4 vs 5.4e-4 noise floor |
| Qwen3.5-4B | hidden 3456, 32 + 15 layers, 8.3B | exact | inside the noise floor |
